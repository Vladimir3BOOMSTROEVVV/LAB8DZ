# Домашнее задание (Условие)

Составить программу, которая вычисляет для целого N, заданного пользователем, значение произведения от 1 до N с шагом 0.1

# 1. Алгоритм и блок-схема

### Алгоритм

1. Объявить переменные n, res, i типа float.
2. Присвоить переменной res значение 1.
3. Ввести число n с клавиатуры.
4. Выполнять цикл for, начиная с i = 1, пока i < n, увеличивая i на 0.1 после каждой итерации.
5. На каждой итерации умножать res на текущее значение i.
6. Вывести полученное произведение.

# 2. Реализация программы

Программа реализована на языке C.

Для ввода координат используется функция scanf().

res = 1 задаёт начальное значение произведения.

for (i = 1; i < n; i += 0.1) перебирает числа с шагом 0,1.

res *= i умножает результат на очередное число.

printf("%f", res) выводит результат на экран.
